# A portable media production contract

Resolve deliverable, subject, audience, aspect ratio, duration/resolution, factual
copy, brand constraints, supplied references, identity requirements, and budget.
Use context already supplied; ask only for a missing detail that materially
changes the result. Keep explicit provider/model choices throughout the job.

For a product image, preserve actual geometry, markings, colors, and intended
use. Plan shot, angle, light, backdrop, scale, and crop. For brand assets, keep
palette/type/logo invariants stable across variants. For a thumbnail, make the
composition readable at its delivered size and keep the promise truthful.

For video, plan the narrative, shot sequence, subjects, continuity, transitions,
sound, and deliverable before submitting a long render. Record which assets
are locked and which may vary. Identity training and provider-specific studio
products require their real native workflows; this guide does not imitate them.

Discover the actual endpoint schema and supported reference limits. Use native
reference/edit operations for local changes instead of regenerating all content
when that loses fidelity. Do not assume another provider's flags or model names
work on the selected service.

Retain inputs, prompt/model version, job IDs, outputs, and relevant cost evidence.
Recover an existing unknown submission before retrying. Bound concurrent jobs
to the authorized budget and provider limits. A timeout does not prove no charge
or no remote job.

Inspect actual media for subject/reference fidelity, legible truthful text,
composition, required formats, and relevant continuity/audio behavior. A success
status or output URL alone does not establish quality. Use the current `unslop`
catalog when available, and distinguish final outputs from pending jobs.
