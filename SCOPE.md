# Scope

tkstack manages personal agent dotfiles: current upstream skills, custom skills
and agent definitions, harness settings, and standards for working with them.

The supported baseline includes Pstack with Cursor Team Kit, Theo's Tstack,
Matt Pocock's skills, Emil Kowalski's design-engineering skills, and Uncle Bob's
ub-mode, plus the other sources listed in `sources.lock.json`. Installation,
compatibility adaptations, integrity checks, and clear documentation belong
here. Normal dotfiles setup refreshes upstream sources and tools; `vendor/`
retains historical reference snapshots. Changes to upstream projects belong
upstream rather than being silently edited into those snapshots.
