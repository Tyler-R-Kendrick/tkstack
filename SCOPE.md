# Scope

tkstack manages personal agent dotfiles: pinned upstream skills, custom skills
and agent definitions, harness settings, and standards for working with them.

The supported baseline includes Pstack with Cursor Team Kit, Theo's Tstack,
and Matt Pocock's skills. Installation, compatibility adaptations, integrity
checks, and clear documentation belong here. Changes to those upstream
projects should be proposed upstream and adopted through an explicit snapshot
update rather than silently edited into `vendor/`.
