tkstack checkout, `scripts/tool.py rtk` launches the selected runtime and native
hooks leave commands unchanged when it is absent. A standalone copied skill
does not contain this launcher or install the binary.

Verify the executable identity with supported version/help and gain commands.
Shell-output filtering does not affect direct file tools. Preserve an unfiltered
path and use the actual runtime's bypass mechanism when exact errors, bytes,
identifiers, quoting, or requirement evidence matter. Verify command semantics
and native permissions still hold after rewriting.

Measure output/token reduction separately from billing or performance claims.

routing explicit; two context transformations do not automatically compose
