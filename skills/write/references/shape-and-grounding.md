# Shape an argument

Read the raw material before choosing the story. State the reader's starting
knowledge, the thesis, and the promise the opening makes. Choose one clear
route from that starting point to the intended conclusion.

Each passage makes one move: establish context, explain a concept, show an
example, offer evidence, answer an objection, or draw a supported implication.
Track the concepts it needs and the concepts it introduces. If a later claim
depends on an unfamiliar idea, introduce that idea first or simplify the claim.
Defining a term without establishing the underlying idea does not ground it.

Use prose for connected reasoning, lists for genuinely parallel items, tables
for repeated comparisons, and code only when it carries the explanation.
An example should do explanatory work. Cut a paragraph that neither advances
the argument nor supplies necessary evidence.

Interactive mode may offer two or three openings or next passages and write
the chosen one. Do not impose that rhythm on a request for a finished draft.
In either mode, keep the original material intact and preserve external edits.

Before delivery, follow the reader's path through the actual saved draft. Check
the opening's promise, transitions, prerequisite concepts, claims, citations,
and ending. Stop when the purpose is fulfilled; leftover notes need not appear.
For an educational explanation, use a worked concrete case before generalizing
and distinguish demonstrated understanding from merely recognizing terminology.
