# Triage labels

Use the canonical role names as label strings:

| Role | Label |
| --- | --- |
| Awaiting triage | `needs-triage` |
| Needs additional information | `needs-info` |
| Ready for an agent | `ready-for-agent` |
| Requires a human | `ready-for-human` |
| Declined | `wontfix` |

During an authorized triage task, inspect the repository's labels and create
missing labels as needed. Installation configures this vocabulary locally;
it does not modify GitHub's label inventory.
