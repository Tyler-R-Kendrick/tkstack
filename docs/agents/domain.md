# Domain docs

This is a single-context repository. Read `GLOSSARY.md` for its vocabulary and
the relevant decisions under `docs/adr/` before changing the setup.

Keep domain terms consistent across skills, installation code, and documentation.
When a decision conflicts with an existing ADR, identify the conflict and update
the decision explicitly. Prefer a small shared glossary to repeated terminology
in every skill.

The repository's engineering and workflow standards are in `docs/standards.md`.
